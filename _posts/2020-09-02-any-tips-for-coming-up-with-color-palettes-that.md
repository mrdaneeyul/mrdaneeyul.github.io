> Any tips for coming up with color palettes that match up with a retro game system like the gameboy color? I'm looking to start a project similar to yours!

## As far as the palette goes: the Game Boy Color had a LOT of color capabilities. Pretty much any color you can think of. Due to the GBC screen adding sort of an olive/tan tint though, I’d suggest not doing pure white. I also prefer colors that are slightly desaturated.

## And, one of the biggest things that make it look like GBC are the restrictions: 4 colors per 8x8 sub-tile, 4 colors per sprite (1 of which can be alpha). I bend these restrictions, but rarely!

## Hopefully that helps!
