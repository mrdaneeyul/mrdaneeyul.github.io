**Sunday**<br>More work over the weekend on collisions between moving objects! This’ll probably take a few more days.<br><br>**Monday**<br>I got about an hour of sleep last night… gamedev ain’t happening.<br><br>**Tuesday**<br>Updated my version of GMS2. Added some missing vector scripts (thanks to PixelatedPope as usual) and got closer to getting the move/collision script working!  Also updated [GMEdit](https://yellowafterlife.itch.io/gmedit) (a script editor for GameMaker) and started using that again because it’s nice. :)<br><br>**Wednesday**<br>After lots more work on that move script, some cleanup of the vector scripts, etc., we’re in business! For reference, the script is called MoveActor, written by PixelatedPope. Essentially the script accounts for moving an “actor” (an object in the game that acts, such as the player, enemies, etc.) as well as any environmental effects on that actor’s movement (pushing from other actors, ice, conveyor belts, etc.), then runs the script that moves the actor based on all those variables, and finally runs the script that moves and calculates collisions. <br><br>**Thursday**<br>Finished migrating from GitKraken to TortoiseGit for version control, as well as resolved a corrupted git file issue. That issue was preventing me from committing any changes, so I’ve been a bit nervous about losing the massive progress I’ve made. Luckily it’s resolved! :)<br><br>**Friday**<br>Finally figured out a longstanding issue where the game ran absolutely awfully on my powerhouse desktop. Turns out vsync on a 60fps game doesn’t mix well with 144hz monitors! Very relieved to fix this. <br>
