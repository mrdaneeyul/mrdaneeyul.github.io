New camera transitions! It’s doing an ease out (cubic) function here, which looks MUCH better than just moving it linearly.

In my newly minted, amateur opinion, *all* game developers should learn about easing functions. They’re so very useful for making movements more lifelike. [Here’s a good visual with all the equations](http://gizma.com/easing/).

Oh, and here are some [awesome free easing functions for GameMaker](https://marketplace.yoyogames.com/assets/2395/easing-and-tweening) in case you don’t want to write them all out. :) Feel free to let me know if you have any questions on how to use them!
